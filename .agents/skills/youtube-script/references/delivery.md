# 話し言葉と画面指示

台本は読み物ではなく読み上げ原稿。目で追って意味が通るだけでは足りず、
声に出して詰まらず、耳で聞いて一度で分かる必要がある。

## 目次

1. 話し言葉に直す
2. 一度で聞き取れる文にする
3. 数字・固有名詞・専門用語
4. 間とリズム
5. 画面指示の書き方
6. 台本の記法

## 1. 話し言葉に直す

| 書き言葉 | 話し言葉 |
| --- | --- |
| 〜を実施します | 〜をやります |
| 〜が可能です | 〜できます |
| 〜する必要があります | 〜しないといけません |
| 非常に | すごく / かなり |
| 〜における | 〜での |
| および / ならびに | と |
| 前述の通り | さっき言ったように |

- 体言止めを続けない。ナレーションでは無機質に聞こえる。
- 接続詞を省きすぎない。話し言葉は文字より論理の手がかりが少ない。
- 語尾を単調にしない。「〜です」が 4 回続いたら 1 つ変える。
- チャンネルの文体が硬いなら、無理に崩さない。合わせる先があるならそちらが優先。

## 2. 一度で聞き取れる文にする

- 一文は 60 字以内を目安にする。超えたら切る。
- 主語と述語を離さない。修飾句を主語と述語の間に挟まない。
- 二重否定を使わない。「〜しないわけではない」は「〜することもある」に直す。
- 同音異義語は文脈で判別できるようにするか、言い換える(「機構」→「仕組み」)。
- 指示語を続けない。「それ」「これ」が 2 回続いたら名詞に戻す。
- 括弧の中身は読めない。補足は独立した文にするか、テロップに回す。

## 3. 数字・固有名詞・専門用語

- 数字は口に出せる形で書く。「約 3 割」「およそ 1 万 2 千円」「2 倍以上」。
- 桁の大きい数字、細かい小数、URL、型番は、口頭では概数にしてテロップに正確な値を出す。
- 初出の専門用語は、その場で 1 文で言い換える。言い換えられない用語は使わない。
- 人名・社名・製品名の読み方が複数あるものは、台本にルビか読みを添える。
- 英語の略語は初出でフルスペルか意味を添える。2 回目以降は略語でよい。

## 4. 間とリズム

- 重要な一文の前に間を置く。`[間]` を台本に書く。
- 話題が変わる箇所に `[間]` と場面転換の指示を置く。
- 列挙は 3 つまで。4 つ以上はテロップに回して、口頭では代表例だけ言う。
- 長い説明の後に短い文を 1 つ置くと、聞き手が追いつける。
- 同じ言い回しの繰り返しは、意図的なら残す。無意識ならばらす。

## 5. 画面指示の書き方

ナレーションと指示を混ぜない。指示は角括弧で独立した行にする。

| 記法 | 用途 |
| --- | --- |
| `[テロップ: ...]` | 画面に出す文字。読み上げ文と違ってよい |
| `[B-roll: ...]` | 差し込む映像。何を撮る/使うかを具体的に |
| `[画面収録: ...]` | 操作画面。どの画面のどの操作かまで書く |
| `[図解: ...]` | 用意する図。何と何の関係を示す図か |
| `[間]` | 一拍置く |
| `[カット]` | 場面転換 |
| `[効果音: ...]` | 音の指示 |
| `[要確認]` | 事実の裏づけが取れていない箇所。収録前に潰す |
| `[PR 表示]` | 案件の明示が必要な箇所 |

指示で守ること。

- 用意できない素材を前提にしない。手元にない映像、権利のない音源、撮影できない場所を指示しない。
- テロップは読み上げ文の要約にする。全文を出すと視聴者は読むだけになり、音声を聞かなくなる。
- 1 章に最低 1 つは画面変化を入れる。話者の固定ショットだけが続く区間を作らない。
- ショートは全編テロップ前提。音声なしで意味が通るかを確認する。

## 6. 台本の記法

- 見出し `## 章タイトル (目安 1:30)` で章を区切る。尺見積りスクリプトはこの見出しで集計する。
- ナレーションは地の文として書く。行頭に記号を付けない。
- 指示は角括弧の行にする。尺の計算から自動的に除外される。
- 話者が複数いる場合は `話者A:` のように行頭に付ける。集計時は話者名を除いて数える。
- コメントや作業メモは `<!-- -->` で囲む。納品前に消す。
