# 動画の型別の骨格

テーマが同じでも、動画の型が変われば章立ても語り方も変わる。依頼から型を判断し、
迷ったら「視聴者がこの動画を見終わったとき何ができるようになるか」で選ぶ。

## 目次

1. 解説・教養
2. レビュー・比較
3. チュートリアル・ハウツー
4. ニュース・時事
5. 体験・検証
6. 対談・インタビュー
7. vlog・日常
8. 商品紹介・案件

## 1. 解説・教養

視聴者は理解を求めている。結論を先に出し、そこへ至る道筋を見せる。

骨格: 結論 → なぜそう言えるか → 前提知識 → 詳細 → 例外と限界 → まとめ

- 前提知識は必要最小限。全部説明しようとすると本題に入る前に離脱する。
- たとえは 1 論点に 1 つ。たとえの説明にたとえを重ねない。
- 「諸説あります」で逃げない。どの説を採るか決め、根拠を示す。
- 反対意見に触れる。触れないと、知っている視聴者から信用を失う。

## 2. レビュー・比較

視聴者は買うかどうかを決めたい。結論(買いか、誰に向くか)を先に出す。

骨格: 結論 → 評価軸の提示 → 各軸の実測・実感 → 欠点 → 誰に向くか・向かないか

- 評価軸を先に宣言する。軸なしの感想は比較にならない。
- 欠点を必ず入れる。良い点だけのレビューは信用されない。
- 価格と時点を明示する。`[テロップ: 2026年9月時点の価格]` のように画面にも出す。
- 提供品・案件なら冒頭で明示する。台本の該当箇所に `[PR 表示]` を入れる。
- 未実測の性能を実測のように語らない。「カタログ値では」と区別する。

## 3. チュートリアル・ハウツー

視聴者は再現したい。完成形を先に見せ、手順を順に追う。

骨格: 完成形 → 必要なもの → 手順 1..n → つまずきやすい点 → 確認方法

- 手順は視聴者の画面と一致させる。バージョンや環境を冒頭で明示する。
- 1 手順 1 動作。複数の操作を 1 文に詰めない。
- 待ち時間、失敗しやすい箇所、元に戻す方法を入れる。
- 画面収録の指示を手順ごとに置く。`[画面収録: 設定 > 詳細 > 有効化]`
- 手順の総数を先に言う。「全部で 5 ステップです」は離脱を減らす。

## 4. ニュース・時事

視聴者は何が起きたかと、それが自分にどう関係するかを知りたい。

骨格: 何が起きたか → 事実関係 → 背景 → 影響 → 今後の見通し → 現時点で不明なこと

- 事実と推測を明確に分ける。語尾で区別する(「〜しました」と「〜とみられます」)。
- 出典を口頭とテロップの両方に出す。一次情報を優先する。
- 収録時点を明示する。`[テロップ: 2026年9月7日時点の情報]`
- 未確定の情報を確定として語らない。不明点を最後にまとめて挙げる。
- 断定できない部分を尺の都合で断定に丸めない。

## 5. 体験・検証

視聴者は結果と過程の両方を見に来ている。

骨格: 何をやったか → なぜやったか → 過程(山と谷)→ 結果 → 分かったこと → 再現性

- 結果を冒頭で全部見せるか、伏せるかを決める。伏せるなら過程を面白くする責任が生まれる。
- 条件を明示する。期間、回数、環境。条件のない検証は主張にならない。
- 失敗も入れる。うまくいった部分だけの構成は薄くなる。

## 6. 対談・インタビュー

台本は逐語ではなく、進行台本として書く。

構成物: 導入ナレーション → ゲスト紹介 → 質問リスト(本命と予備)→ 深掘りの分岐 → 締め

- 質問は「はい/いいえ」で終わらない形にする。
- 本命の質問は 5〜7 問。それ以上は入らない。
- 各質問に、想定回答と、そこから伸ばす追加質問を 1 つ用意する。
- ゲストの肩書き、実績、宣伝したいものを事前に確認して台本に書く。誤記は失礼にあたる。
- 進行役の台詞(相槌、言い換え、時間管理の合図)も書いておく。

## 7. vlog・日常

台本を書き込みすぎると不自然になる。書くのは骨格と要所の台詞だけ。

構成物: 冒頭のフック → その日の目的 → 場面リスト → 各場面の一言 → 締めの所感

- 場面ごとに「何を撮るか」と「そこで何を言うか」を 1 行ずつ。
- 全部の台詞を書かない。話す内容の要点だけを箇条書きで渡す。
- 冒頭のフックだけは書き切る。ここは即興に任せない。

## 8. 商品紹介・案件

- 案件であることを冒頭で明示する。台本の先頭に `[PR 表示: 提供 ◯◯]` を置く。
- 依頼主から渡された訴求点と、こちらの実感を分けて書く。
- 効果を断定する表現、比較優位の断定、医薬品的な効能の表現は避ける。関連する法規や
  プラットフォームの規約に触れる可能性がある箇所は `[要確認]` を付けて依頼者の確認に回す。
- 価格、キャンペーン期間、条件は必ず時点付きで書く。
